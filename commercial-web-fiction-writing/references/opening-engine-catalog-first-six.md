Use this catalog **before drafting** to pick a single primary opening engine. Do not run three engines at full load in chapters 1–6.

## 3. Six-chapter skeletons

### 1 Contract death
Hear ledger → evidence object → family fight / stop labor → critical loss of control → signed protocol vs home invasion → **sign in the contempt zone**.  
Checklist: stop service → stop subsidy → draw boundary → external counsel → legal effect.

### 2 Marvel delay
Abnormal tenderness then split → **challenge · wager · third-party acceptance** → elder locks divorce → substitution feel → danger because “she can” → **stab again after rescue**.  
Discipline: marvel must happen in a public rating system.

### 3 Reunion loss-of-control
Ritual co-frame → “don’t know you” → graded loss-of-control → disappear order → **real rope** (friend/case) → active hide broken by fake task.  
Discipline: shame uses a wrong script (reader knows the truth).

### 4 Cold exit / keep-child
Opening hidden-child nuke → on-duty collision → propose divorce + countdown contract → welcome-new-mistress ritual → stop household logistics line → forced-apology reverse kill → **“I bless you”**.  
Discipline: child withheld from male lead; title “protocol” must show paper within ~10 chapters.

### 5 Higher-seat offset
Checkpoint rebirth → decide new patron same chapter → land higher seat → public cut of old match → household **refuse to admit fault** → info war.  
Discipline: higher seat should also have a loss-of-control reason; identity can stay unreported.

### 6 Survival purge
Escape → clear one enemy per chapter → soft outside / hard inside → equal-retaliation → local allies as witnesses → **demand principal / report**.  
Discipline: action chapter titles; male lead light only.

### 7 Multi-heir bargaining
Same-night dual miss → six-year raise flashback → return for divorce/household register → kids vs tycoon → **face recognize** → money/verify first → dual “abandon” misread.  
Discipline: kids have split jobs; heroine still decides each chapter; DNA/reunion can wait.

## 4. Shared hard rules

1. Title states end-state direction; body sells path and cost.  
2. Inside chapter 1: old state fails + new choice (new books stricter).  
3. Recurring conflict must change one of five variables: information / relationship / resource / map / cost.  
4. Pleasure ≈ regaining decision rights (not only face-slap).  
5. Emotional evidence objects > abstract labels.  
6. Chapter titles are hooks: contrast / irony / question / action / identity prefix; rotate every 5–8 chapters.  
7. Chapter end may close the action but plants next-action foreshadow.  
8. Engine relay windows (elastic): 1–3 new state; 4–10 first promise + second engine; 11–20 swap causality, close small hooks, stage loop.  
9. IAA length: ~2000–2500 chars; warn below 1500 or above 3000; do not pad.  
10. Extract mechanisms only — never copy signature prop chains or full causal sequences.
